# 💮 YDK スマート電子印鑑スタジオ (YDK Smart Seal Studio)

株式会社YDKリノベーション / やればできるこJAPAN株式会社 向けのクラウド対応・高精細電子印鑑作成＆PDF直接押印Webアプリケーションです。

---

## ✨ 主な機能

1. **4種の電子印鑑エンジン & YDK実印プリセット内蔵**
   - **🏢 代表者印（二重丸印）**: 外周回文（会社名）＋内周2行役職名の自動円弧配置
   - **🟦 会社角印（縦書き複数行）**: 改行テキストに応じた自動均等割付・縦書きレンダリング
   - **💮 認印・小判印**: 縦書き氏名印・楕円（小判）枠・文字長体（縦横比）調整
   - **📅 日付データ印（領収・検収・承認）**: 上段（部署・役職）・中段（日付帯）・下段（氏名・承認）の3段構造
   - **高解像度YDK実印・角印プリセット**: 実際の株式会社YDKリノベーション代表者印・会社角印の透過印影データをワンクリック呼び出し可能

2. **双方向リアルタイム同期プレビュー（3カラム・1画面完結UI）**
   - 左パネル（印鑑デザイン設定）の変更が、中央パネル（印鑑透過プレビュー）および右パネル（PDFページプレビュー上の押印済みスタンプ）へ即座に同期反映されます。

3. **PDF直接押印・マルチページ管理・XML互換入出力**
   - PDFのドラッグ＆ドロップ読み込み（初回起動時はサンプル請求書・見積書PDFを自動生成）
   - ページ上でのクリック押印、ドラッグ移動、サイズ変更、個別削除
   - `pdf-lib` による高解像度スタンプ合成PDF出力、透過PNG単体出力、XML設定保存/読込

4. **4形態マルチターゲット対応 (`bundle_all.mjs`)**
   - **Web App (Vercel / GitHub)**: ブラウザからURLを開くだけで利用可能
   - **単一HTML版 (Googleドライブ直起動)**: 1ファイル（約2.19MB）に全アセット・PDF Workerをインライン封入
   - **Google Apps Script (GAS) Webアプリ**: Googleドライブへの直接保存・読込に対応
   - **Chrome拡張機能 (Manifest V3)**: Chrome右横のサイドパネル（`sidePanel` API）およびフルタブ切替に対応

## 🚀 開発・ビルド手順

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド + マルチターゲット（単一HTML / GAS / Chrome拡張）一括生成
npm run build
node bundle_all.mjs
```
